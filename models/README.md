# Pretrained Deep Learning Models

This directory holds the OpenCV Zoo ONNX model files:
- `face_detection_yunet.onnx` (~232 KB) - YuNet Face Detector
- `face_recognition_sface.onnx` (~38.6 MB) - SFace Face Recognizer

If missing, they are automatically downloaded by `face_engine.py` on first run from the official OpenCV Zoo GitHub repository.
